# Registro de licencias y permisos de contenido

Este registro debe completarse antes de publicar o monetizar cada recurso. Un archivo sin evidencia suficiente debe quedar en estado `REVISAR` o `RETIRAR`.

| Recurso | Tipo | Autor/titular | Fuente | Licencia o permiso | Territorio/fecha | Estado | Responsable | Evidencia privada |
|---|---|---|---|---|---|---|---|---|
| | PDF / DOCX / audio / imagen | | | | | REVISAR | | |

## Estados permitidos

- `APROBADO`: existe licencia o autorización verificable y compatible con la publicación.
- `REVISAR`: falta evidencia, hay dudas de titularidad o la licencia no está confirmada.
- `RETIRAR`: no debe permanecer accesible públicamente.

Este archivo no debe contener claves ni copias de documentos privados. Las evidencias deben conservarse en un almacenamiento restringido y con un responsable identificado.
